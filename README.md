# ugly-outsider-cgi

一个用于 Codex 的照片风格转换 skill：把真实照片改造成一种“《牛来》式”的粗糙、荒诞、低预算 early 3D CGI 画面。

这里的“《牛来》式”不是复制电影角色、镜头或素材，而是提炼一种可复用的视觉方向：像没有受过专业训练的初学者，用早期 3D 软件勉强完成了一个角色和场景。主体和动作仍然认得出来，但模型比例笨拙、布线规划不足、材质贴图失真、渲染质量低下，整体完成得很不成熟。

## 这不是普通 low-poly

目标不是漂亮的游戏资产、潮玩模型或复古滤镜，而是：

- 结构完整，但形体抽象、夸张、丑陋、笨拙；
- 像初学者凭感觉拼出的第一版角色 blockout；
- 低面数曲面仍然保留弧面，不把所有东西变成立方体或体素；
- 贴图像错误地贴在模型上，而不是干净的程序化材质；
- 粗糙度来自主体上的大颗粒 bump/displacement，而不是全画面噪点；
- 画面像低配工作站输出的早期动画截图。

## 核心视觉规则

### 1. 先保证识别，再夸张造型

保留主体数量、物种或身份、主要动作、关键道具、颜色关系和原始构图。比例和造型可以明显偏离原图，但不能丢掉主体的基本结构。

### 2. 新手感来自建模规划不足

模型应该出现：

- 头部过大、躯干过短或过厚；
- 四肢粗细和长度不一致，爪子或脚过重；
- 部件像分别做完后粗略拼接；
- 局部突然面多、局部突然面少；
- 相邻部件的面大小和 edge flow 不一致；
- 接缝、转折、塌陷和压扁感没有被清理。

这些问题要像一个人的笨拙选择，而不是模型被程序炸碎。禁止缺肢、断裂、大洞、随机漂浮部件和碎片化身体。

### 3. 五官要风格化，但不能错位

五官可以极度简化、夸张或笨拙，但位置关系必须可读：双眼大致在同一水平线上，鼻子位于口鼻块中央，嘴部位于鼻子下方。丑感来自尺寸、形状、材质和僵硬表情，不来自随机错位的五官。

### 4. 贴图必须真的坏掉

需要看见具体的 bitmap/cutout 故障：

- 不匹配的贴图岛；
- 拉伸、压扁、拖长的 UV 纹理条；
- 不同区域的 texel density 不一致；
- 错误比例的图案、明显接缝和颜色溢出；
- 几块低分辨率图像被粗暴地硬贴到曲面上。

单纯的像素化、脏色块或多边形明暗，不等于坏贴图。

### 5. 大颗粒粗糙度要和低面数分开

主体和服装上要有能在中景读出的粗大颗粒、凹坑、结块和多孔火山石般的 relief。它们来自失败的 roughness/bump/displacement，不是细小噪点，也不是 polygon facets 的替代品。

背景、眼睛和关键识别点保持相对干净；不要把整张图处理成统一麻点。

### 6. Early 3D 渲染

使用 flat shading 或 crude Gouraud shading、低分辨率 raster、锯齿边缘、有限色深、硬色阶、简单 bitmap filtering、低动态范围和糊成块的硬阴影。避免现代 PBR、电影级灯光、光滑 subdivision 和高级材质分层。

## 使用方式

在 Codex 中调用：

```text
$ugly-outsider-cgi
```

输入照片应作为 edit target，而不是只作为氛围参考。提示词需要明确：

1. 主体、动作和 2–4 个识别锚点；
2. 哪些比例要夸张；
3. 哪些部件要像新手粗略拼接；
4. 哪些区域使用坏 bitmap 贴图；
5. 哪些主体表面使用大颗粒粗糙度；
6. 背景如何简化。

普通单图编辑只生成并交付一张最终图。不要先生成造型版、再生成材质版，因为第二次生成会重新改写整张图，无法可靠锁住第一版几何。

## 交付前检查

- 一眼能认出原照片主体、物种或身份和主要动作；
- 形体像初学者做的，而不是专业 low-poly 游戏资产；
- 大形比例明显错误，但结构完整；
- 五官位置正常，风格化来自简化和夸张，不是错位；
- 能看见局部坏贴图、UV 拉伸、纹理接缝和颜色溢出；
- 能看见主体上的大颗粒粗糙度、凹坑和结块；
- polygon facets、bitmap 故障和 roughness relief 三者彼此可区分；
- 背景没有被错误地全部做成麻点；
- 没有现代 PBR、漂亮游戏资产、潮玩感、电影级灯光、血腥或恐怖故障。
